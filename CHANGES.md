# SAILOR Replication Package — Changes

All modifications made to the original replication package.

---

## New Scripts

### `run_sailor_sqlite.sh`
Runs the full SAILOR pipeline on SQLite only.
- Auto-clones SQLite at a pinned commit hash
- Creates `build.sh` in the dataset directory (SQLite has no top-level `./build.sh`)
- Phase 1 skip guard: skips CodeQL + spec generation if `findings.json`, `project.bc`, and specs already exist
- Phase 2+3 skip guard: resumes from last completed spec via `summary.tsv` row count
- Removes stale Docker container by name before re-running Phase 2+3
- All Docker commands run with `sudo`
- Mounts `sailor.sh`, `sailor_prepare.sh`, and `sailor_engine/` as volumes so host edits take effect without rebuilding the image

### `run_sailor_wireshark.sh`
Runs the full SAILOR pipeline on Wireshark only.
- Dynamically discovers the commit hash from tag `v4.2.0` via shallow clone, caches it in `dataset/.wireshark_commit`
- Generates `configs/wireshark_<commit>_vul_config.sh` if not present
- Same Phase 1 / Phase 2+3 caching and resume logic as SQLite runner
- `--memory=32g` on both Docker runs to prevent CodeQL OOM failures
- All Docker commands run with `sudo`

### `run_sailor_imagemagick.sh`
Runs the full SAILOR pipeline on ImageMagick only.
- Dynamically discovers the commit hash from the given tag, caches it in `dataset/.imagemagick_commit`
- Generates `configs/imagemagick_<commit>_vul_config.sh` if not present (autoconf build)
- Same Phase 1 / Phase 2+3 caching and resume logic
- `--memory=32g` on both Docker runs
- All Docker commands run with `sudo`
- Initially used tag `7.1.1-33`; updated to `7.1.2-19` (latest available)

### `cleanup_sqlite.sh`
Removes all SQLite intermediary files to allow a clean restart:
- `dataset/<sqlite_commit>/`
- `sa_outputs/sqlite_*`
- `specs/sqlite_*`
- `se_runs/sailor_engine/sqlite_*`
- `results.tsv`

## Modified Scripts

### `sailor.sh`
Added pre-LLM triage skip guard. If `specs/<project>/triage_order.txt` and `specs/<project>/triage_stats.json` both exist, triage is skipped and the script resumes directly at Phase 2+3 (LLM harness synthesis). Prevents re-running the full ranking pass after a crash.

### `sailor_engine/build_project_bc.sh`
Multiple fixes for reliable bitcode extraction across project types:

**Libtool / autoconf fix (ImageMagick, SQLite):**
- `CC=wllvm` and `CXX=wllvm++` are now passed explicitly as configure arguments (not just as env vars) — libtool bakes the compiler into its wrapper at configure time; env-only export is insufficient
- Same flags passed to `make` invocation: `make -j$(nproc) CC=wllvm CXX=wllvm++`

**Stale install prefix fix:**
- `rm -rf build/` added to the deep-cleaning step — prevents `extract-bc` from finding a stale `.a` installed by the CodeQL-phase build (which uses the system compiler, not wllvm) instead of the freshly compiled one

**Artifact search strategy fix:**
- Now prefers `.libs/*.a` (libtool's real wllvm-compiled archive) over top-level `.a` files, which may be libtool stubs or install-prefix artifacts without embedded bitcode
- Falls back to top-level `.a`, then `.so`, then build executables in that order

**`find` pipe safety:**
- All `find` calls that feed into pipes now use `-printf "%s\t%p\n" | sort -nr | head -1 | cut -f2 || true` to avoid `set -euo pipefail` killing the script silently on empty results

### `Dockerfile`
Added missing Wireshark build dependencies to the `apt-get install` block:
```
libglib2.0-dev libgcrypt20-dev libpcap-dev libc-ares-dev libbz2-dev
```
These are required by Wireshark's CMake build system and were absent, causing `FindGLIB2.cmake` to fail.

### `.gitignore`
Added:
- `*.csv` — result files
- `*.tsv` — summary/results files
- `.claude/` — Claude Code session data

## Generated Config Files

### `configs/wireshark_54eedfc6_vul_config.sh`
Auto-generated by `run_sailor_wireshark.sh`. Wireshark CMake build with all non-core targets disabled (`-DBUILD_wireshark=OFF`, `-DBUILD_tshark=OFF`, etc.) and optional libraries disabled (`-DENABLE_GNUTLS=OFF`, `-DENABLE_LUA=OFF`, etc.) to minimize build surface and avoid missing-dependency failures. Includes `rm -rf build` to prevent stale `CMakeCache.txt` from caching negative dependency results.

### `configs/imagemagick_<commit>_vul_config.sh`
Auto-generated by `run_sailor_imagemagick.sh`. Autoconf build with `--disable-shared --enable-static --without-x --without-perl --without-magick-plus-plus --disable-openmp`.

## Key Bugs Fixed

| Symptom | Root Cause | Fix |
|---|---|---|
| `Invalid source root` for SQLite | Dataset directory not cloned | Added auto-clone in runner script |
| `./build.sh: No such file or directory` | SQLite has no build.sh | Runner creates one wrapping `./configure && make` |
| Script exits silently after header | `find` on missing `specs/` dir returns non-zero, killed by `set -euo pipefail` | Guard with `[ -d dir ] && SPEC_COUNT=$(find ...)` |
| `container name already in use` on re-run | Previous run killed without cleanup | `docker rm -f` before Phase 2+3 |
| Triage re-runs after crash | `sailor.sh` edits had no effect — script runs from inside Docker image | Added volume mounts for `sailor.sh`, `sailor_prepare.sh`, `sailor_engine/` |
| `FindGLIB2.cmake` failure for Wireshark | Missing `libglib2.0-dev` in Docker image | Added to Dockerfile apt-get block |
| `Dataset import failed with code 2` | CodeQL OOM during analysis | Added `--memory=32g` to Docker runs |
| `.llvm_bc ELF section missing` for ImageMagick | libtool bakes compiler at configure time; env `CC=wllvm` ignored | Pass `CC=wllvm` explicitly to `./configure` and `make` |
| Wrong `.a` found by `extract-bc` | Stale install-prefix `.a` (no wllvm bitcode) found before `.libs/*.a` | `rm -rf build/` in cleaning step; prefer `.libs/` in artifact search |
